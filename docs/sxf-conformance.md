# SXF（P21）対応状況と完全適合への課題

最終更新: 2026-08-10

## 現状（実装済み・証拠）

- `src/domain/edelivery/sxfP21.ts`（147 行）で AP202 サブセットの試作エクスポータを実装。
  - 円弧は `TRIMMED_CURVE`（master_representation=.P.）で出力（2026-08-09 対応）。
  - 線分・ポリライン等の基本図形を出力。
- テスト: `tests/unit/domain/edelivery/sxfP21.test.ts`（試作範囲の往復・構造検証）。
- 本画面: 印刷・出力画面の「SXF（試作）」チェックから `.P21` をダウンロード可能。

## 未対応（根拠）

| 項目 | 現状 | 必要対応 |
| --- | --- | --- |
| 属性エンティティ（SXF_LAYER / SXF_ATTRIBUTE 等） | 未実装 | 国土交通省 CAD 製図基準・SXF 仕様書（AP202）の属性定義を精査し、レイヤー名・線種・図形属性をエンティティ化 |
| CAD 製図基準（線種・文字スタイル・寸法規約） | 一部のみ | 発注者の製図基準（SXF 版）に合わせた既定値・検証 |
| 楕円・スプライン・ハッチ・注記 | 未対応（試作範囲外） | SXF エンティティ定義の追加実装 |
| 電子納品チェックシステムでの実地検証 | 未実施 | 各発注者の電子納品チェックシステムで検証（人工程） |
| 完全適合の自動断定 | しない | 本ファイル・評価書のとおり、機械出力は「試作」として扱い、最終確認は人間 |

## 推奨アプローチ

1. 対象発注者（例: 国土交通省直轄・地方自治体）の電子納品要領を一次情報で特定し、要求 SXF 版を確定する。
2. 属性エンティティの要件を `src/domain/edelivery/sxfP21.ts` の TODO として Issue 化する。
3. 電子納品チェックシステム（外部）で往復検証する工程を `docs/edelivery` へ追加する。
4. 適合確認後も「適合」表示は人による承認を必須とする。
