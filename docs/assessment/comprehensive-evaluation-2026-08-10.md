## 3. 強み（15 件）

1. 必須 CAD 37 機能が実装単位で突合され、円弧/楕円/スプライン/改訂雲/平行2線/測距面積/配列/尺度まで対話ツール化
2. 幾何演算エンジン（トリム/フィレット/オフセット/スナップ等 17 ファイル）が純関数＋テストで高品質
3. 型安全性（Brand ID・Result・単位付き座標）と Command パターン Undo/Redo（差分・上限 100）
4. DXF 往復（単位/角度/線種是正）・PDF（日本語フォント/表題欄）・CSV 出力が実装・テスト済み
5. 数量⇔図形連動・図面健全性チェック（未接続/stale 数量検出）という土木業務視点の品質機構
6. 承認ワークフロー（照査→承認・checksum 照合・承認後改変防止）と楽観ロック 409
7. 監査ログがハッシュチェーン（並行分岐防止・検証 API）で改ざん検知可能
8. Cloudflare Access 認証＋JWT 二次検証＋CSP＋レート制限＋fail-closed の多層防御
9. IndexedDB 自動保存＋復旧候補 UI（オフライン端末正本）
10. テスト 1,466 件・Browser E2E・性能 CI・カバレッジ閾値（85%）・SBOM 決定性
11. ADR 駆動の設計記録（16 本）と要件/設計 3 文書の整合
12. 週次 Neon バックアップ＋リストア検証・ロールバック手順・インシデント手順
13. 電子納品（要領 R5.3 準拠チェック・禁則文字・人確認必須）と PDF 編集（結合/分割/墨消し物理削除）
14. PAdES 埋め込み署名（ByteRange・自己署名証明書）と SXF 試作まで自前実装
15. 移行記録・アーカイブ（git bundle・Issue/PR 全量）と削除済み旧リポジトリの追跡可能性

## 8. AI 設計（チャット目的化しない）

**基本方針**: AI は「時間削減・検索/判断支援・説明可能性・安全性・費用対効果」で評価し、ルール・検索で十分な領域（コマンド実行・禁則文字チェック・承認ルート）には AI を入れない。

| 領域 | 方式 | 設計要点 |
| --- | --- | --- |
| 類似図面・過去成果の検索 | RAG（属性＋文書ベクトル、Neon pgvector） | 権限スコープ（案件メンバーのみ）で検索、引用元（図面 ID/改訂/行）を明示、信頼度表示、人間が最終判断 |
| 数量根拠の説明生成 | 構造化抽出＋テンプレート生成 | 図形/数量アイテムの決定性データから説明文を生成（LLM は整形のみ）、誤り時はログで原因追跡 |
| 現場写真の出来形分類 | 分類モデル（外部 API 利用可） | 入力画像の秘匿化・破棄ポリシー、分類結果は「候補」表示、承認必須 |
| 数量乖離・工程遅延の異常検知 | 予測/異常検知（統計モデル） | 単純モデルで説明可能に、しきい値は運用で調整、アラートは人間承認フローへ |
