残課題 対応手順書（索引）

CivilDraft-Web-CAD ・ 更新日: 2026-08-10 ・ 作成: 金曜開発枠（8/9）の続き

本ページは、外部環境・人間実施が必要な残課題を「誰が見ても分かる詳細手順」としてまとめたものです。 各手順は、対象の前提・準備・実行・検証・失敗時の対処までを順番に記載しています。

目次

#課題状態手順書必要環境

2 SXF 完全適合（属性エンティティ・CAD製図基準） 実装＋外部検証 SXF 完全適合手順 電子納品チェックシステム（外部）
2b PDF/A 認証（ICC 埋め込み＋verapdf 検証） 外部検証 PDF/A 認証手順 verapdf（Java）、sRGB ICC
3 PAdES の認証局証明書チェーン＋タイムスタンプ局（RFC 3161） 実装拡張＋外部連携 PAdES 証明書・TSA 連携手順 認証局、TSA、openssl

共通の注意事項

  • 秘密情報の取り扱い: 接続文字列・秘密鍵・トークンは必ず環境変数またはシークレット管理で扱い、リポジトリへ commit しないでください。ログ出力にも含めないこと。
  • 承認ゲート: 本番 DB（Neon main）への DDL 適用、証明書・TSA の外部契約は人間の明示承認後に実行してください。
  • 検証を先に: どの手順も「適用前チェック → 適用 → 適用後チェック」の順で進め、成功を確認してから次へ進んでください。
  • ロールバック: 各手順書の「失敗時の対処」を参照してください。
