# 📗 CivilDraft 利用者操作マニュアル（2026-08-12）

対象: CivilDraft-Web-CAD（本番 URL: `https://civildraft-web-cad.mirai-dx-platform.com`）
対象利用者: 設計・施工技術者／現場監督／照査・承認者／経営層／協力会社（閲覧）
関連文書: [README](../../README.md)・[運用手順書](operations-manual.md)・[障害対応](incident-response.md)

> 本マニュアルはロール（閲覧者/技術者/監督者）別の基本操作を説明します。
> 画面は利用開始後の実案件データに応じて表示されます。本番 DB へ未適用の機能
> （チェックイン/アウト・断面データ等）は、人間による migration 適用後に利用可能になります。

## 1. ログインとロール

1. 本番 URL を開くと Cloudflare Access のログイン画面へ遷移します。組織のアカウントでサインインしてください。
2. ロールは IdP グループ名（`civildraft-supervisor` / `civildraft-engineer` / `civildraft-viewer`）で決まります。

| ロール | できること | できないこと |
| --- | --- | --- |
| 閲覧者（viewer） | 案件・図面・数量・現場説明の閲覧、PDF/DXF出力 | 編集・保存・照査・承認・管理操作 |
| 技術者（engineer） | 閲覧＋作図・編集・保存・数量算出・出力 | 承認 |
| 監督者（supervisor） | 技術者の操作＋照査・承認 | — |

## 2. ホーム画面（案件一覧）

- 「ホーム・案件一覧」で参加中の案件・照査待ち・承認待ち・自動保存の復旧候補を確認できます。
- 案件カードをクリックすると案件詳細（図面一覧）へ移動します。
- 技術者/監督者は「＋ 新規案件・図面」から案件と初期図面を作成できます（閲覧者は非表示）。
- 検索欄で案件名・図面番号を検索できます。
- URL は `#/...` 形式で、案件詳細や監査ログなどをブックマーク・共有できます（ブラウザの戻る/進むにも対応）。

## 3. CAD 編集（作図）

1. 案件詳細の図面行の「CAD編集で開く」、またはサイドバー「CAD編集」でエディタを開きます。
2. 左パネルのツール（線・矩形・円・円弧・楕円・ポリライン・文字・寸法・ハッチ等）を選択し、キャンバスへクリック/ドラッグで作図します。
3. 保存は自動（IndexedDB、約3秒デバウンス）です。ヘッダーの保存状態表示（自動保存済み/保存中）を確認してください。
4. Undo/Redo は `Ctrl/Cmd+Z`・`Ctrl/Cmd+Y`（またはツールバー）。コマンドパレットは `Ctrl/Cmd+K`。
5. 図面の健全性チェックで、未接続数量・stale数量・未対応DXF要素・未承認改訂などを検出できます。
6. 技術者/監督者は「共有保存」「共有再読込」でサーバーへ保存・再読込できます（閲覧者は編集UIが表示されません）。

### 図面の排他編集（チェックイン/アウト）
- 本番 migration 0007 適用後、図面のチェックアウト（編集権取得）→ 編集 → チェックイン（解放）ができます。
- 他者がチェックアウト中の図面は編集できません（409 エラー）。

## 4. 自動保存と復旧

- 端末ブラウザ内（IndexedDB）へ自動保存されます。別の端末には自動同期されません（共有保存はサーバーへ）。
- ホームの「自動保存の復旧候補」で下書きを「復元」または「破棄」できます。
- ブラウザを閉じても次回起動時に復旧候補が表示されます。

## 5. 数量・断面

- 「数量集計」で図面から数量を算出（工種・規格・単位・数量の集計）できます。
- 数量明細の「図面で確認」で根拠図形をハイライト、CAD編集で図形を選ぶと明細行がハイライトされます（双方向連動）。
- 「縦横断管理」で断面データを確認できます（本番 migration 0008 適用後、実案件の断面データを保存・読込できます）。

## 6. 照査・承認フロー

| 状態 | 意味 | 次の操作 |
| --- | --- | --- |
| 作成中（draft） | 編集中 | 提出（技術者） |
| 照査中（inReview） | 提出済み・照査待ち | 照査（監督者） |
| 承認待ち（pendingApproval） | 照査完了 | 承認（監督者） |
| 承認済み（approved） | 確定（承認後は改変防止） | 出力・電子納品 |
| 差戻し（returned） | 修正指示あり | 修正して再提出 |

- 承認後の図面は改変されないよう保護されます（checksum 照合・楽観ロック）。

## 7. 出力（PDF/DXF/Excel）

1. 「印刷・出力」で出力形式（PDF・DXF・Excel）を選択します。
2. 「出力を実行」でブラウザからファイルがダウンロードされます。
3. PDF は A3 等の用紙・縮尺・図面枠・表題欄つきのベクター出力です（日本語フォント込み）。
4. 電子納品用には「電子納品」画面でフォルダ構成・命名規則・禁則文字のチェックを行ってください（最終確認は人間）。

## 8. 電子納品

- 国交省「工事完成図書の電子納品等要領（令和5年3月版）」＋運用ガイドライン【土木工事編】に基づくチェックを実行できます。
- チェックは自動判定せず、必ず人の最終確認が必要です。
- SXF(P21) 出力は試作レベルです。発注者への正式提出前に電子納品チェックシステムでの検証が必要です。

## 9. 監査ログ（監督者/管理者向け）

- 「監査ログ」で保存・承認・出力・認証イベントを確認できます。
- ハッシュチェーン検証でログの改ざんがないことを確認できます。

## 10. よくある質問（FAQ）

**Q1. 自動保存された下書きが表示されない**
同じブラウザで作業してください（IndexedDB は端末・ブラウザごとに保持）。別端末で続ける場合は「共有保存」を使用してください。

**Q2. 保存に失敗した**
保存状態表示に警告が出ます。通信（VPN/社内ネットワーク）と Access ログイン状態を確認し、再試行してください。解決しない場合は [障害対応](incident-response.md) に従い報告してください。

**Q3. 図面が編集できない**
図面がチェックアウト中、承認済み（改変防止）、またはロールが閲覧者の可能性があります。担当者または管理者へ確認してください。

**Q4. オフラインでも使えますか**
閲覧・作図の一部と自動保存はオフラインでも動作しますが、共有保存・認証が必要な操作はオンラインが必要です。

**Q5. 出力した PDF の文字が化ける**
日本語フォント（Noto Sans JP サブセット）が埋め込まれます。環境依存の問題が疑われる場合はバージョンとブラウザを添えて報告してください。

**Q6. 他社（協力会社）に図面を見せるには**
閲覧者ロールのアカウントを発行し、案件メンバーとして招待してください。共有リンク（URL）は Access 認証を通過したユーザーのみ閲覧できます。
